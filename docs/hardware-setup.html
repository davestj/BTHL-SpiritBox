Hardware Setup

RTL-SDR (required)

Any RTL2832U-based SDR dongle works through SoapySDR. Plug it in before launching; the app auto-detects and opens the first device it finds.

# Confirm the OS sees your dongle
SoapySDRUtil --find
E4000 tuner — important. Some dongles (e.g. the Nooelec SMArt XTR) use the Elonics E4000 tuner, which cannot tune below roughly 52 MHz. On those devices the AM broadcast band (530–1700 kHz) is physically unreachable — you'll see PLL not locked errors and the sweep will skip those steps. Use an FM or VHF profile on an E4000. See Sweep Profiles.

GQ EMF-390 (optional)

The EMF-390 connects over USB serial (CH340 bridge, VID 0x1A86). The app scans serial ports on startup and connects automatically if it finds one. EMF readings stream at 100 ms intervals and are correlated with radio-band voice events.

  • Note the baseline EMF reading for the room before you start.
  • A spike near a transcribed response raises that event's correlation score.

Microphone (optional)

Used by Interactive mode to transcribe your questions. Any input device the OS exposes works; the app converts it to 16 kHz mono for Whisper automatically.

macOS permission. The first time you enable the mic, macOS asks for microphone access. The app ships with the required usage description, so just click Allow. If you previously denied it, re-enable under System Settings → Privacy & Security → Microphone.

Don't share the SDR

The RTL-SDR can't be opened by two programs at once. BTHL-SpiritBox enforces a single running instance, and you should not run it alongside another SDR app (e.g. SpectraSentry) on the same dongle simultaneously.
