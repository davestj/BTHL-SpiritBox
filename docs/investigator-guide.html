Investigator Guide Running an EVP session that produces legible responses

A spirit-box session is a conversation. BTHL-SpiritBox rapidly sweeps radio frequencies to create a stream of fragmentary audio; the theory of the technique is that a response can manipulate that stream into recognizable words. Your job is to ask clear questions, leave room for an answer, and let the AI transcribe both sides so you have a reviewable record.

The investigation loop

  1. Set up — connect the SDR (and EMF-390 if you have one), load a Whisper model, and choose a capture mode.
  2. Baseline — note the room's EMF level and ambient noise before you begin.
  3. Open — state the date, time, and location out loud, then read an opening script from the Session Templates.
  4. Ask & wait — ask one short question, then hold a silent window of 5–10 seconds so a response can form and be transcribed.
  5. Acknowledge — if you get a response, repeat it back and build on it.
  6. Close — thank whoever may be present and end the session cleanly.
  7. Review — File → Save Transcript… and read it back; the log labels INVESTIGATOR questions and RESPONSE lines separately.

Reading the transcript

In Interactive mode the transcript interleaves both voices:

[ 12.30s] INVESTIGATOR: "Is anyone here with us?"
[ 14.80s] RESPONSE @ 99.500 MHz: "...here..."
[ 21.10s] INVESTIGATOR: "Can you say my name?"

Your own questions are never correlated with EMF spikes — only radio-band responses are — so a question is never mislabeled as a spirit response.

Getting legible responses

Ask short questions. One idea per question. Yes/no and single-word answers are easiest for the sweep to render.
Leave silence. The pause after a question is where answers appear. Don't talk over the box.
One voice at a time. Multiple investigators talking at once muddies both the audio and the transcript.
Note timestamps. When something stands out, say the time aloud so you can find it in the saved transcript and WAV.
Stay grounded. Sweep audio is noise by design; the mind readily hears words in randomness (pareidolia). Treat single fragments skeptically. Look for responses that are contextually relevant, repeatable, and ideally correlated with an EMF event.
