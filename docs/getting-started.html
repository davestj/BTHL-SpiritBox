Getting Started From installer to your first session in a few minutes

BTHL-SpiritBox is a desktop app for macOS and Windows. There's nothing to compile and no command line — just install, plug in your gear, and start a session.

1. Install

macOS

Open BTHL-SpiritBox.pkg and follow the installer. The app lands in your Applications folder. Launch it from there or Spotlight.

Windows

Run BTHL-SpiritBox-Setup.exe and follow the installer. Launch it from the Start menu or the desktop shortcut.

First launch. You'll see the loading splash, then the investigation console. macOS may ask for microphone permission the first time you use Interactive mode — click Allow.

2. Connect your equipment

  • RTL-SDR dongle — required. Plug it into a USB port before (or after) launch; the app finds it automatically. This is what sweeps the radio spectrum.
  • GQ EMF-390 — optional. Connect it by USB to add EMF readings and correlation.
  • Microphone — optional. Your computer's built-in mic is fine for capturing your spoken questions in Interactive mode.

See Hardware Setup for details and the Device Capabilities panel, which shows exactly what your hardware can do.

3. Start sweeping

On launch the app connects your SDR and begins an FM sweep automatically — you'll hear the characteristic rapid radio sweep. Pick a different band any time from the profile selector.

4. Turn on transcription

To have spoken responses written down, load a voice model from the Whisper menu (Whisper → Load Model…). A recommended model is installed with the app; you can switch to a higher-accuracy one any time. See Voice Models.

5. Choose how you'll capture

In the Transcriptions panel pick a capture mode:

  • Interactive — your questions and responses are transcribed (full Q&A).
  • Standalone — responses only; your voice isn't recorded.
  • Passive Listen — leave it running to catch spontaneous responses.

6. Run the session

  1. Open Session Templates and read an opening script.
  2. Ask one short question, then wait 5–10 seconds for a response.
  3. Watch the transcript fill in, labelled INVESTIGATOR and RESPONSE.
  4. When you're done, use File → Save Transcript… to keep a copy.
That's it. Read the Investigator Guide for technique, and keep the Session Templates handy during your first few sessions.
